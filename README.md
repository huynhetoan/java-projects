# Java Projects 

GUI development and file I/O to object-oriented modeling and data analytics.

## Projects Overview

### CoffeeShop

A GUI-based Java application

#### Features
- Built with `JFrame`, `JPanel`, and `GridLayout`
- Modular windows for ordering and viewing
- Action listeners for responsive button behavior
- Exit with confirmation dialog

### UABSystem

A console-based employee management system. Reads from `uabEmployee.txt` Allows users to manage staff records through an interface.

#### Features
- Reads and parses employee data into multiple `ArrayList`s
- Supports adding, updating, deleting, and displaying employees
- Helper methods in `UABPerson` class
- Handles multiple roles: Faculty, Student, Advisor, ITProfessional, Doctor

### EmployeeDataAnalyzer

Analyzes employee records from a CSV file. Outputs insights.

#### Features
- Parses `employee_data.csv` into department objects
- Calculates average salary per department
- Identifies longest-tenured employees and department leads
- Filters employees by years of service
